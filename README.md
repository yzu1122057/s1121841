# 陳祐聖 Portfolio Website

## 如何開啟
1. 解壓縮這個資料夾。
2. 直接雙擊 `index.html` 就可以開啟。
3. 建議用 VS Code 的 Live Server 開啟，動畫與圖片載入會更穩定。

## 檔案結構
- `index.html`：網站內容與作品分類
- `style.css`：版面、配色、動畫、RWD
- `script.js`：滾動進場與互動效果
- `assets/`：作品圖片與去背素材

## 修改方式
- 想改文字：打開 `index.html`
- 想改顏色 / 大小 / 排版：打開 `style.css`
- 想換圖片：把新圖片放進 `assets`，再改 HTML 裡面的圖片檔名
